## 制御の流れ

```
TIM1 (20 kHz, センター揃えアップダウン, ARR=1800)
  │  上りで CNT = 1750 (頂点の50カウント手前) を通過 → OC4REF 立ち上がり → TRGO2
  │  低側FETのON区間は頂点を中心に広がるので、ここが区間の中央 = 平均電流が取れる
  ↓
ADC1 が U相/V相 の電流を1点サンプリング
  ↓ DMA転送完了割り込み  ← ここが制御ループのタイミング
HAL_ADC_ConvCpltCallback()   [bldc.c]
  ├─ BLDC_UpdateEncoder()    20 kHz : 角度追従オブザーバ (2次PLL) → 機械角と角速度
  ├─ BLDC_CurrentLoop()      20 kHz :
  │     電流取得 → 過電流判定 → 電気角 (+角度遅れ補償) の sin/cos
  │     → Clarke → Park → Id/Iq の PI → 逆起電力・dq干渉の FF
  │     → 電圧ベクトルの円制限 (+アンチワインドアップ)
  │     → 逆Park → SVPWM → CCR1/2/3 書き込み
  ├─ BLDC_OuterLoop()         1 kHz : 過速度判定、速度/位置PID → Iq指令 [A]
  └─ BLDC_DirectIqLoop()     20 kHz : (外側ループ以外の周期) トルク/制動/停止モードのIq指令 (指令の素通し)
```

外側ループは CCR 書き込みの後に回す (期限があるのは CCR 書き込みまで。Iq 指令の反映は次の周期から)。

モード (`BLDCMode`): STOP / SPEED / POSITION / TORQUE / BRAKE。

- SPEED: 指令を `MAX_ANGULAR_SPEED` でクランプし、`MAX_ANGULAR_ACCEL` でスルーレート制限してから PID。
- POSITION: 目標角との偏差 (`FOC_AngleDiff` で ±π) をそのまま PID に入れる素の構成。偏差 `POSITION_DEADBAND_RAD` 未満かつ速度
  `POSITION_SETTLE_SPEED_RAD_S` 未満で整定とみなし電流を0にする。
- TORQUE / BRAKE / STOP: PID を通らず指令を素通し。BRAKE は `-tanh(ω/BRAKE_BOUNDARY_SPEED_RAD_S)` (パデ近似 `BLDC_TanhApprox`) で
  チャタリングを防ぎ、`BRAKE_DEADBAND_SPEED_RAD_S` 未満はトルク0 (係数は 1 kHz で更新)。
- 全モード共通で、最終的な Iq 指令を上位指定の `torque_limit` (= `svc.iq_limit`、上限 `MAX_CURRENT`) で飽和させる。
  詳細は [SERIAL_PROTOCOL.md](SERIAL_PROTOCOL.md)。

## 割り込み優先度

20 kHz の制御ループを最優先にしてジッタを抑えている (`CurrentSense_Init` 内で設定)。

| 割り込み | 優先度 |
|---|---|
| DMA1_Channel1 (ADC1 = 制御ループ) | 0 |
| SysTick | 1 |
| DMA1_Channel4-7 (UART) | 2 |
| DMA1_Channel2 (ADC2) | **無効化** (値は DMA が更新するので不要) |

## 実行時間

`-O2` ビルドで **CPU 使用率 約44%** (割り込み 平均 22.1 µs / 最大 27.8 µs、入口から CCR 書き込みまで最大 20.4 µs、周期 50 µs。
2026-10-19 実測)。測り方は [OPTIMIZATION.md](OPTIMIZATION.md) の「プロファイラの使い方」。
CCR 書き込みが `ISR_DEADLINE_US = 23.4 µs` を超えるとデューティの反映が1周期ずれるので、それが上限。

割り込みの中を触るときは次を壊さないこと。

- **倍精度演算を作らない**。`mymath.h` の `PI` / `TWO_PI` は `double` で、単精度FPUのみの Cortex-M4 ではソフト演算になる。
  割り込み内では `PI_F` / `TWO_PI_F` / `FOC_NormalizeRadians()` / `FOC_AngleDiff()` を使い、リテラルには `f` を付ける。
- **sin/cos は `FOC_SinCos()`** (512点テーブル + 線形補間。縮約を1回で済ませ sin と cos を同時に返す)。
  入力範囲は任意なので事前に正規化しない。`mymath.h` に三角関数を足さない。libm の `tanhf` / `cosf` も使わない。
- **PWM 出力は `TIM1->CCRx` 直書き** (`BLDC_WritePwm`。`PwmOut_Write` は1相約100命令)。
- **平方根は `FOC_Sqrt()`** (VSQRT.F32 一命令)。
- **float の比較・`Abs()` / `Constrain()` を増やさない**。`VCMP`+`VMRS` は1回8〜10サイクルかかる。
  `Abs()` は float で `VABS.F32` になるよう振り分け済み、デューティのクランプは整数比較にしてある。
- エンコーダのラジアン変換係数は事前計算する (`BLDC_UpdateEncoderScale`)。

`arm-none-eabi-objdump -d build/ProgramV4.elf` で割り込み配下に `__aeabi_*` (倍精度) が無いことを確かめる。

## 変調とデューティ上限

SVPWM は min-max 方式 (三次高調波重畳)。最大値と最小値の中点を全相から引き、線間電圧を変えずに
相電圧のピークを下げて、母線電圧の利用率を正弦波変調の 2/√3 (約15%) 倍にする。

ローサイドシャントの都合で `MAX_DUTY = 0.88` (`MAX_DUTY_CCR = 1584`) に制限しており、
出せる相電圧振幅は `(0.88 - 0.5) × 2/√3 = 0.439 × Vdc` (理論上限は 0.577 × Vdc)。これが `MAX_MODULATION_RATIO`。

さらに電圧を出したくなったら:

1. **アンプの整定時間を実測して `CURRENT_SENSE_SETTLING_COUNTS` を詰める**。現在の 144 カウント (2.0 µs) は
   データシートからの保守的な見積もり。手順は [OPTIMIZATION.md](OPTIMIZATION.md)「アンプ整定時間を ADC で測る」。0.92 程度まで見込める
2. ADC1 のサンプリング時間を 61.5 → 19.5 cycles に短縮する (基板の RC フィルタ次第)
3. デューティが高い相の電流を推定で補う (相電流再構成)

## 電気角

`elec_theta = (mech_theta + ω̂ × angle_delay) × POLE_PAIRS`

- 観測角は `θ_meas = θ_lin − encoder_offset_theta − lut(θ_lin)`。θ_lin は ADC 値の線形写像 (向き `encoder_dir` 込み)、
  lut は校正で作る補正テーブル (磁石の偏心・INL)。校正後は `mech_theta × POLE_PAIRS` が d軸 (ロータ磁束方向) に一致する。
  静的なずれは校正 6 が δ0 として測ってオフセットに足し込むので、手動のオフセット定数は持たない。
- **角度遅れ補償**: AS5600 の内部フィルタ (約1 ms) と演算遅れ (0.075 ms) のため推定角は実位置より遅れ、
  回転中は速度比例の角度ずれ δ = ω_e × 遅れ になる。ω̂ ぶん先に進めて打ち消す。
  補償しないと 120 rad/s で電気角が約49°ずれ、逆起電力が d軸に漏れる (実測)。遅れ時間は校正 6 で自動測定する。

**確認方法**: `STATUS_PRINT_INTERVAL_S` を有効にして高速で回し、`Vd` がほぼ0なら合っている。
負に大きければ補償不足、正に振れたら進めすぎ。無負荷でトルク指令を入れたとき `Id` が 0 付近、`Iq` が指令に追従するのも目安。

## エンコーダ (AS5600 アナログ出力) の扱い

機械角の誤差は**極対数倍 (7倍) されて電気角の誤差になる**ので、ここは特に慎重に扱うこと。

### 起動時に機械角を実測値で確定させる (`encoder_primed`)

0 から実角度へ収束させると電気角が何回転もして電流制御が破綻するので、`BLDC_UpdateEncoder` の初回は `mech_theta = theta_meas` とする。
`BLDC_Init` と、校正でオフセットを変えたあとに `encoder_primed = false` で張り直す。

### 角度追従オブザーバ (2次PLL)

速度は角度の微分ではなく、推定角 θ̂ を観測角に追従させるループの内部状態として θ̂ と ω̂ を同時に得る。
AS5600 のアナログ出力はレール付近で飽和し、継ぎ目の手前で角度が凍結するので、微分だと継ぎ目のたびに
大きな速度スパイクが出て速度制御が1回転ごとに「がくっ」となる。

```
e   = θ_meas - θ̂                (イノベーション)
ω̂ += PLL_KI * e * dt            (速度推定 = 積分器)
θ̂ += (ω̂ + PLL_KP * e) * dt      (角度推定)
```

閉ループは標準2次系で `ω_n = √KI`, `ζ = KP/(2√KI)`。ζ=1 として `KP = 2ω_n`, `KI = ω_n²`、
`PLL_OMEGA_N = 900 rad/s`。調整は `PLL_OMEGA_N` だけでよい。量子化ノイズを増幅せず、等速回転で定常誤差ゼロ、欠測は ω̂ で外挿する。

観測値のゲートは2種類あり、**「観測できない」と「推定がずれている」を区別することが必須**:

- **飽和**: 生の ADC 値がレール付近 (判定幅 `encoder_margin` は校正で静止ノイズ σ から決める) なら角度情報が無いので棄却し、外挿する (最大 `ENCODER_REJECT_MAX` = 50 ms)。
  **飽和を抜けた直後の `ENCODER_SAT_HOLDOFF_SAMPLES` (4 = 200 µs) も棄却する**。継ぎ目では出力が反対のレールへ移る途中の値を拾い、
  それが継ぎ目の手前のそれらしい角度に見えてイノベーションの判定をすり抜けるため。
- **グリッチ**: イノベーションが `ENCODER_INNOVATION_LIMIT_RAD` を超えたら `ENCODER_GLITCH_MAX` (1 ms) だけ棄却。続くなら推定が本当にずれているので棄却をやめ、全量を PLL に通して再ロックさせる。

棄却に打ち切りが無いと、ロータを急停止させたとき θ̂ の自走を「異常な観測」と誤認し続け、永久にロックが戻らない
(自分のずれを理由に自分を補正しない自己維持ループ)。

速度推定 (積分パス) のイノベーションは**ロック中のみ** `PLL_SPEED_ERROR_LIMIT_RAD` で制限する
(継ぎ目の段差が全量 ω̂ に入って1回転ごとに Iq がスパイクするのを防ぐ)。再取得中に制限すると
`dω̂/dt` が頭打ちになり急減速に追従できない。比例パスは常に無制限なので、段差は角度補正として吸収される。

**再ロックの速さ**: 引き込み範囲はおよそ `PLL_KP`。`PLL_KP ≥ MAX_ANGULAR_SPEED` を満たしていればどの運転速度から急停止しても再ロックする。
`PLL_OMEGA_N` を下げるときはこの条件を割らないこと。

`ENCODER_INNOVATION_LIMIT_RAD` (0.25 rad) は継ぎ目の `emax` より十分大きくすること。近いと偶然の連続超過で
再取得モードに入り、積分パスの制限が外れて速度スパイクが出る。

**確認方法**: `STATUS_PRINT_INTERVAL_S` を有効にすると継ぎ目の状態が出る。

| 表示 | 意味 | 読み方 |
|---|---|---|
| `sat:` | 飽和で棄却したサンプル数 | 1回転ごとに出るのは正常な検出 |
| `glt:` | イノベーション過大で棄却した数 | 継ぎ目の遷移グリッチのぶん |
| `emax:` | 採用したイノベーションのピーク [rad] | **継ぎ目の段差そのもの**。0.01〜0.02 程度なら校正良好、0.05 超ならエンコーダ校正をやり直す |

### 盲点とスケール

レール付近の飽和で 1回転あたり角度が読めない区間 (盲点) がある。ADC 値 `[min, max]` がカバーするのは 2π ではなく
**2π − 盲点幅** なので、`BLDC_UpdateEncoderScale` は盲点幅を差し引いてスケールを作る
(2π を割り当てると盲点を外挿で渡るたびに段差が出る)。盲点幅は校正 3 で飽和サンプルの割合から求める。
校正側と運転側は同じ判定 `BLDC_IsEncoderSaturated` を使うこと。

AS5600 の OUT ピンにコンデンサを足すのは逆効果 (遷移が緩やかになり中間値を拾うサンプルが増え、位相遅れも増える)。
根本対策は I²C 接続 (次の基板。CurcuitV4 は SDA/SCL 未接続)。

## 校正とモータ定数

スイッチ (PA12) を押しながら起動すると `BLDC_Calibrate` が次を実行し、**全部成功したときだけ** `BLDC_Init` が `BLDC_SaveCalibration` で1回で Flash に保存する。
**既定値は持たない**: Flash に有効な校正値が無ければ `BLDC_IsCalibrated()` が偽で、app はトルク上限を 0 に固定する (駆動しない)。
校正電流 `CALIB_CURRENT_RATIO × MAX_CURRENT` (3 A) を基準に、各測定の電圧・電流・速度は自動で決まる。

測定はすべて**制御ループの中で記録・平均する** (`BLDC_CalibIsr` 20 kHz / `BLDC_CalibOuterIsr` 1 kHz)。
メインループの `HAL_Delay(1)` は約 2 ms 待つので周期の基準にしてはいけない (加速度を約1/2に読み J を約2倍にする)。
電流のゼロ点校正は割り込み開始前に済ませ、モータ定数の校正はすべて**電流制御と過電流保護が働く状態**で行う。

| # | 測定 | 方法 | 得るもの |
|---|---|---|---|
| 1 | R, L | 強制角で Vd を直接印加 (PIバイパス)。Id が校正電流に届く電圧 V_cal を探し、**電気角6か所 (60°刻み)** で 0.25〜1.0×V_cal の4点 (各0.1秒平均) → 計24点を最小二乗。θ と θ+180° で相電流が反転するので、電流センサのオフセットと相ごとのデッドタイムの偏りが打ち消される。τ は各角度2回・計12回の同期加算から、電流LPFを逆算して ln(1−i/i_ss) の傾きで | R, V0 (デッドタイム), L = τR、角度ごとの R |
| 2 | 電流帯域 | 強制角で Id ステップ (各回4回同期加算)。実測帯域が `CURRENT_BW_TARGET_HZ` になるよう設計帯域を補正し、もう一度測って確認 (オーバーシュート 15% 超・狙いの7割未満は失敗) | `current_bw_hz` |
| 3 | エンコーダ | 電流制御の強制転流 (1周2秒)。静止ノイズ σ → 1周目で極値、2周目でレール付近のヒストグラム → 最頻値をレールに。レール探しの2周は倍速。校正電流の2倍 (6 A) で正転1周+逆転1周。真の機械角 φ = 強制角/P を 128 ビンに分けて生値を平均 | レール、判定幅 4σ+2、盲点幅、回転方向、d軸オフセット |
| 4 | J/Kt と摩擦 | トルクモードで +I 加速 → −I 減速。同じ速度帯 (0.2〜0.8 × `J_TOP_SPEED`) の加速度差から J/Kt、和から摩擦。I は 0.1×MAX_CURRENT から、速すぎ/遅すぎの両側が分かったら対数二分探索。見つけた I と 1.5I (上限超なら 0.75I) で各方向2回、計4回の平均。ばらつき 30% 超は失敗 | `j_per_kt`, `friction_current` → 速度ゲイン |
| 5 | 補正テーブル | 速度制御で回してから出力を切り、惰性で回る間に θ_lin が 128 本の格子線を横切った時刻を記録。正逆2回ずつ。各回の真の角度を時刻の3次式とし、格子線ごとの残差 (= センサの誤差) と交互に最小二乗 | 補正テーブル (偏心・INL) |
| 6 | ψm と角度遅れ | 速度制御で正逆 ±(1〜4)/4×試験速度の8点、各0.5秒平均。Vq から ψm と V0、Vd/Vq の比から各点の δ を出し δ = δ0 + ω_e·Δt を当てはめ | ψm、遅れ、静的な電気角のずれ δ0 |
| 7 | 確認試験 | 試験速度の半分で正逆0.5秒ずつ回して emax (0.1 rad 超は失敗、0.05 超は注意)。emax が出た生値と「飽和を抜けて何サンプル目か」も表示する。試験速度の 1/4→3/4 の指令変更で、ランプへの追従誤差・行き過ぎ (段差の 30% 超は失敗)・最後0.2秒の残留誤差 (5 rad/s 超は失敗) | 合否のみ (保存するかどうか) |

所要時間は1分以内が方針 (惰性回転・加減速の時間は摩擦と慣性で変わるので、最後に実測の所要時間を表示する)。

**順序の理由**: 2, 3 は 1 の電流PIゲインが要る / 4 は電気角 (3) が要る / 5 は惰性で `COAST_REVS` 周回れる
開始速度を摩擦と J/Kt (4) から決め、速度ゲイン (4) で回す / 6 は補正テーブル (5) を入れた角度で測る
(テーブルなしだと電気角が P·ε 揺れ、Vq の平均が ψm·J0(P·ε) に縮んで ψm と Kt を低く読む)。

**母線電圧**: 校正中はメインループ (app の `GetSensors`) が止まり `BLDC_SetSupplyVolt` が呼ばれないので、
`BLDC_CalibOuterIsr` が ADC の値を直接読んで追従する (時定数 約50 ms)。R と ψm は電圧指令から計算するので、
電源電圧の誤差はそのまま誤差になる。`BLDC_Init` にも実測の母線電圧を渡すこと。

**エンコーダ校正の要点**:
- 正逆の平均で摩擦による引き込み遅れと AS5600 の遅れが相殺される。レールはヒストグラムの最頻値 (ビン平均の最小/最大だと内側に偏る)。
- 失敗判定: レンジ不足 / 回転方向が決まらない / θ_lin − φ の隣接差 > 2π/P/3 (1極対の滑り・`POLE_PAIRS` の不一致) /
  ロータの遅れ (正逆差の半分) が電気角 45° (`ENC_LAG_MAX_E`) 超 / 有効ビン < 3/4。
- 電流を校正電流の2倍にするのは、保持を強くして負荷の摩擦 (タイヤ) とコギングによる遅れ・ずれを減らすため
  (タイヤ付きでは 3 A で電気角 24° 遅れた。遅れはほぼ電流に反比例)。流すのは約6.5秒で発熱は問題にならない。

**補正テーブル (惰性回転) の要点** (`CalibMath_CoastSample` / `CalibMath_CoastFit`):
- 強制転流では「センサの誤差」と「ロータの位置ずれ」を区別できず偽の 1周14回の誤差が入る (OPTIMIZATION.md 7)。
  惰性回転は電流0で電気的な脈動が入らず、真の角度は時刻の3次式で表せるので残差がセンサの誤差になる。
- 正転と逆転を平均すると AS5600 のフィルタによる位相遅れが打ち消される。
- 運転時と同じ θ_lin・飽和判定・飽和直後の棄却で記録するので、継ぎ目の扱いが校正と運転で一致する。
- 失敗判定: 1回の惰性で1周回らない / 残差 RMS ≥ 0.01 rad / 補正 > 0.1 rad / 補間した格子線 > 8 本。

**J/Kt**: 同じ速度帯で加速 (+I) と減速 (−I) を比べると速度依存の摩擦も消え `J/Kt = 2I / (a_acc − a_dec)`。
加速度はオブザーバがロック中に追える上限 (`PLL_KI × PLL_SPEED_ERROR_LIMIT_RAD` ≒ 4050 rad/s²) の8割 (`J_MAX_ACCEL`) 以下に抑える
(超えると J を過大評価する)。**機構を付けたまま測れば、その反射慣性と摩擦込みの値になる。**

**Flash**: 通常起動時は Flash から読み出し、マジック・チェックサム・範囲検査を全部通ったときだけ採用する。
項目や意味を変えたら `BLDC_FLASH_MAGIC` を必ず変えること (現行 "BLD8"。履歴は `bldc.h` のコメント)。
ページ消去を伴うので必ず1回で全項目を書く。校正ページ (0x0800F800〜) にコードが侵入しないよう、リンカスクリプトの FLASH は 62K にしてある。

**相抵抗の偏り (2026-10-19 の実機)**: 相ごとに解くと U相 (OUTC) 0.156 Ω / V相 0.116 Ω / W相 0.111 Ω で、U相の経路に約 0.04 Ω 余分な抵抗の疑い。
積分が吸収するので制御は破綻しないが電気角2倍周期の電圧外乱になる。校正の R は6角度の平均。

**参考 (旧手順での実測, 2026-07-29)**: R 0.1928 Ω、L 38 µH、ψm 0.001854 Wb、角度遅れ 1.08 ms。

## ゲイン調整

### 電流PI

```
Kp = L × 2π × f_bw     [V/A]
Ki = R × 2π × f_bw     [V/(A·s)]       (f_bw = 校正 2 で決めた current_bw_hz)
```

L, R は校正値 (Flash) から `BLDC_UpdateCurrentGains()` が計算する。PI のゼロ点 Ki/Kp が R/L を打ち消すので、
閉ループは帯域 f_bw の1次系になる。**帯域の上限はプラントではなく位相遅れ**で、1.5周期の演算遅れと電流LPFを合わせて
700 Hz で位相余裕 約53° (`CURRENT_BW_TARGET_HZ` = 700 が狙い)。実測帯域は設計値より2〜3割低く出るので、校正 2 が実測して設計帯域を補正する。

### 速度/位置PID

出力は Iq 指令 [A]。位置PIDは `BLDC_InitOuterGains()` の手動値 (kp 20 / ki 50 / kd 0.02)。
速度PIDは校正 4 の J/Kt から `BLDC_UpdateSpeedGains()` が計算する (手動の既定値は無い):

```
Kp = (J/Kt) × 2π × SPEED_BW_HZ           [A/(rad/s)]
Ki = Kp × 2π × SPEED_BW_HZ / SPEED_KI_RATIO [A/rad]
FF = (J/Kt) × 指令ランプの加速度 + friction_current × tanh(指令速度 / 境界層)
```

プラント Iq → ω = 1/((J/Kt)·s)。Ki は極零相殺ではなく**積分の折点を帯域の 1/SPEED_KI_RATIO に置く**設計。
FF は PID の出力に足し、飽和判定とアンチワインドアップは FF 込みで行う。

**帯域の上限**: 速度フィードバックは PLL オブザーバ (`PLL_OMEGA_N` = 900 rad/s) の遅れを通るので、
`SPEED_BW_HZ` = 20 Hz (位相余裕 約64°) 程度が実用上限。
`output_limit` は外側ループが毎周期**上位指定のトルク上限 (`svc.iq_limit`)** に入れ替える。
アンチワインドアップ (バックカリキュレーション) がこの値を基準に働くので、飽和中は積分が伸びない。
位置モードの移動速度は torque_limit と負荷と PID ゲインで決まる。速すぎるときは `kd` を上げる
([SERIAL_PROTOCOL.md](SERIAL_PROTOCOL.md) 参照)。

### 逆起電力・dq干渉のフィードフォワード (`CURRENT_FF_ENABLE`)

`Vd -= ω_e·L·Iq`, `Vq += ω_e·L·Id + ω_e·ψm` を PI の出力に足す。応答が速度に依存しなくなり (モデル上 160 rad/s で 1.55 ms → 0.55 ms)、
積分項が電圧余裕を食わなくなる。FF 単独で変調限界を超えると PI が制御権限を失うので `CURRENT_FF_MAX_RATIO` (0.85) で頭打ちにする。
強制角の校正中は ω̂ が実回転と無関係なので FF を使わない。
**符号を間違えると外乱が倍になる**。実機では `Vq(FF...)` を見て、FF が Vq と同符号で速度とともに大半を占めていれば正しい。

### 調整用の状態表示

`STATUS_PRINT_INTERVAL_S` を 0.5f 程度にすると、Iq の指令と実測、Id、Vd、Vq (FF 分) と変調限界、区間内の相電流ピーク、
エンコーダ統計、トルク制限、受信エラー数と、回転中は速度の揺れ (機械角に同期した 1/7/14/42 回/周の成分) が出る。
0 なら関数ごと消えるので常用時のコストはゼロ。

```
Iq: +0.21/ +0.21A  Id: +0.00A  Vd:+0.01V  Vq:+0.22(FF+0.10)/ 3.55V  peak: 0.76A   10.3rad/s  ...
```

`peak` は生の相電流の最大値で、PWM リプルを含むため dq 電流の数倍になるのが正常。

上位なしで回すときは `SELF_TEST_RUN` (普段は必ず 0) を使う。停止 → 10 / 30 / 120 rad/s を補正テーブルあり/なしで 8 秒ずつ回す。

## 停止時はコースト (短絡制動にしない)

`enable = false` のときは **MOE を落として全FETをOFF** にする (`BLDC_SetOutputEnable(false)`)。

全相デューティ0.5は3相短絡と同じで、回転中は短絡制動電流が流れる (過電流保護の直後に一番電流が流れる)。
MOE=0 でコーストさせるには BDTR の **OSSI=1** と `OISx / OISxN = 0` (tim.c の `TIM_OCIDLESTATE_RESET`) が要り、INH/INL がどちらも Low に固定される
(OSSI=0 だと出力ピンが Hi-Z になり DRV8300 の入力が浮く)。`tim.c` は CubeMX の再生成で上書きされるので、OSSI は `BLDC_InitPwmTimer` で立てる。
短絡制動を停止・保護のデフォルトにしてはいけない。

## 保護

- **過電流**: `OVERCURRENT_LIMIT` (15 A) を `OVERCURRENT_TRIP_COUNT` (5) サンプル連続で超えたら `enable = false` にしてラッチし、
  その瞬間の状態を `BLDCTripInfo` に記録する。判定はローパス前の生値。ラッチ中は出力を必ず切り、
  `BLDC_ClearOvercurrent()` で解除 (app ではスイッチを押すと解除)。この基板にはハードの過電流保護が無く、短絡のような急峻な故障には間に合わない。
- **過速度**: |ω̂| が速度・位置モードでは `MAX_ANGULAR_SPEED × OVERSPEED_LIMIT_RATIO` (180 rad/s)、トルク・制動・停止モードでは
  `OVERSPEED_DIRECT_IQ_RAD_S` (270 rad/s) を `OVERSPEED_TRIP_MS` (50 ms) 続けて超えたら、過電流と同じラッチで止める (電気角が狂った暴走対策)。
- **過熱**: `TEMP_LIMIT` (60 °C) 超でラッチ。復帰は 5 °C 下がったとき。
- **電源電圧**: `SUPPLY_VOLTAGE_MIN/MAX_LIMIT` (7〜15 V) の範囲外が `SUPPLY_VOLTAGE_TRIP_DELAY_MS` (500 ms) 連続したときだけ停止してラッチ。
  復帰は範囲の内側に `SUPPLY_VOLTAGE_RECOVER_HYST` (0.5 V) 戻ったとき。
- **無通信**: `SERIAL_TIMEOUT_S` (0.5 s) で停止モード。トルク制限も 0 に戻る。
- **トルク制限**: 上位が何を送っても Kt × `MAX_CURRENT` で頭打ちにし、起動直後・通信断のあと・未校正の間は 0 (動かない)。
- **ウォッチドッグ**: メインループが止まったら IWDG (`WATCHDOG_TIMEOUT_MS`) でリセットする。

異常は赤LED (LED4) の点滅回数で通知する (1回: 過熱、2回: 電圧異常、3回: 過電流、4回: 過速度)。
